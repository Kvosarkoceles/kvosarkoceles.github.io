01 Perfil profesional

Perfil

Soy Desarrollador Full Stack / Web Developer con experiencia en el desarrollo y mantenimiento de aplicaciones web, APIs e integración de sistemas. Mi trabajo combina backend, frontend, integración de servicios, procesamiento de datos y la evolución de plataformas existentes.

He trabajado con PHP, Laravel, CodeIgniter, Node.js, Python, Perl y APIs REST en el backend, y con JavaScript, React y Angular en el frontend, sobre bases de datos PostgreSQL, MySQL, MariaDB y MongoDB, y servicios de AWS como Lambda, SQS, API Gateway, EC2 y CloudWatch.

Una parte importante de mi experiencia se centra en sistemas de rastreo GPS, telemetría y geolocalización: integración de dispositivos, procesamiento de datos, reportes y sistemas de alertas. Me desenvuelvo con comodidad en el mantenimiento y la optimización de plataformas en producción, identificando problemas y desarrollando nuevas funcionalidades e integraciones sobre código existente.
